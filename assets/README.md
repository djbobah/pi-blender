# Model assets

`ai-core` is the single 3D object used by the landing hero.

| File | Role |
| --- | --- |
| `build_ai_core.py` | Source of truth. Procedurally rebuilds the scene and exports the GLB. |
| `ai-core.blend` | Editable Blender scene generated by the script. |
| `ai-core.glb` | Exported runtime asset, copied to `public/models/ai-core.glb`. |

The app loads `/models/ai-core.glb`, so the copy under `public/` is the one served
to the browser. Keep the two files in sync.

## Rebuild

```bash
BLENDER=/path/to/blender npm run model:build
```

`model:build` runs `blender -b --python assets/build_ai_core.py` and copies the
exported GLB into `public/models/`.

## Design constraints

* One faceted graphite core plus three closed rings (no gaps anywhere on a ring).
* Every part owns a disjoint distance-from-origin band, so nothing intersects, and the
  rings sit close together (radial gaps ~0.03):
  core `0.000-0.640`, steel ring `0.705-0.795`, violet ring `0.827-0.917`, cyan ring `0.962-1.078`.
* Graphite stays dark and satin; cyan/violet rings are emissive
  (`KHR_materials_emissive_strength`) with a subtle clearcoat
  (`KHR_materials_clearcoat`).
* No textures, no external URIs, GLB stays well below 5 MB.
